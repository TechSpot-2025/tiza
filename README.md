# Tiza — downloads and website

Tiza is a desktop app for students: at the scheduled time it opens the online class (Zoom, Microsoft Teams,
Google Meet), records it and uploads the recording to the student's own cloud drive.

- Website: <https://techspot-2025.github.io/tiza/>
- Downloads: the [Releases](https://github.com/TechSpot-2025/tiza/releases) of this repository (macOS universal
  dmg, Windows x64 installer). Each release lists the SHA-256 of its files.

This repository holds only the published website (rendered HTML) and the release files. The source code lives
in a separate repository. Contact: victor.cuerdo@me.com.
